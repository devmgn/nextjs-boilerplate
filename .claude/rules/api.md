# API Layer Rules

## Codegen (Orval)

- The spec `openapi/realworld.yml` is vendored from the RealWorld repo (URL in its header). Keep it as-is (excluded from lint / format); to update, re-download it
- `pnpm generate-api` runs Orval (`orval.config.ts`) and regenerates `src/api/openapi/` from the spec
- `src/api/openapi/` is **gitignored**. It is regenerated by `postinstall`, and by the lefthook post-merge / post-checkout / post-rewrite hooks when `openapi/`, `orval.config.ts` or `src/api/api-client/` changed (or the output is missing). Run `pnpm generate-api` manually after editing those by hand or after `git reset` / `git stash pop` / `git restore`, which fire no hook
- **Never manually edit or add files** in `src/api/openapi/` — the output folder is wiped on every run
- Output is split per OpenAPI tag (`mode: "tags-split"`, kebab-case names) with no client barrel `index.ts` (`indexFiles: false`). Import from the specific file. The only root-level files are the mock indexes required by fixtures (`index.msw.ts` / `index.faker.ts` / `index.fixtures.ts`)

| Path | Purpose | Managed |
| --- | --- | --- |
| `src/api/openapi/<tag>/<tag>.ts` | Fetch functions, `get<Operation>QueryOptions` / `get<Operation>SuspenseQueryOptions` / `get<Operation>MutationOptions`, query keys, and hooks | Generated |
| `src/api/openapi/<tag>/<tag>.msw.ts` | MSW handlers (`get<Operation>MockHandler`, `get<Tag>Mock()` for the whole tag) | Generated |
| `src/api/openapi/<tag>/<tag>.faker.ts` | Faker response factories (`get<Operation>ResponseMock`) | Generated |
| `src/api/openapi/index.fixtures.ts` | `defineFixtures` / `respond` / `resolveFixture` (see `mocks.md`) | Generated |
| `src/api/openapi/model/<type>.ts` | Request / response types, one type per file | Generated |
| `src/api/api-client/` | Orval mutator (`apiClient`), `ApiError`, `isApiError()` type guard, and `ErrorType` (= `ApiError`). Orval reads `ErrorType` from the mutator file, so keep them together | Manual |

Tags map to directories, e.g. `Articles` → `articles/`, `User and Authentication` → `user-and-authentication/`.

```ts
import type { GetArticlesParams } from "../api/openapi/model/get-articles-params";
import { useGetArticlesSuspense } from "../api/openapi/articles/articles";
```

## Error Handling

The mutator throws `ApiError` (`status`, raw `body`) so TanStack Query surfaces failures as errors:

- non-2xx responses (if reading the error body fails, `body` is `""` and the status is kept)
- 2xx responses that are not valid JSON

A 204 / 205 or an empty body resolves to `undefined`. Generated `TError` defaults to `ApiError` via `ErrorType`. Do not switch to Orval's `{ data, status }` return style. Narrow caught errors with `isApiError()`.

Responses are **not** validated at runtime; the spec is trusted as the contract.

`ApiError.body` is the raw upstream response. Never show it to users as-is (it can contain HTML error pages or internal details); map the status to a fixed message instead.

## TanStack Query Pattern

- **Components**: use the generated hooks (`useGetArticlesSuspense()`, `useCreateArticle()`, ...)
- **Outside components** (Server Component prefetch, `queryClient` cache access): use the generated `get<Operation>SuspenseQueryOptions` / `get<Operation>QueryKey`. Both share the same query key (`["getArticles", params]`), so prefetched data hydrates the hook

```tsx
// Client Component
const { data } = useGetArticlesSuspense({ limit: 10 });

// Server Component prefetch
await queryClient.query(getGetArticlesSuspenseQueryOptions({ limit: 10 }));
```

Pair the suspense hook with the suspense options when prefetching; `get<Operation>QueryOptions` (non-suspense) is not assignable to `useSuspenseQuery`.
